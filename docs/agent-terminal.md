# Agent Terminal 사용 및 검증 기록

## 사용 방법

`Settings → Tools → SnakeOrCamel → Agent Terminal`에서 동작 안내와 설치된 플러그인·단축키 충돌 정보를 확인하고 연동을 활성화한다. 기본값은 OFF이며 활성화만으로 CLI를 실행하지 않는다. 활성화 여부는 IDE 사용자 설정, 실행 프로필은 프로젝트의 로컬 workspace 설정에 저장한다.

프로필에 이름, 종류(Claude·Codex·Custom), 실행 명령과 작업 디렉터리를 설정한다. 빈 디렉터리는 프로젝트 루트를 사용한다. 실행 명령은 한 줄로 입력하며 옵션을 포함한 원문을 셸에 전달한다. 기본 프로필은 직접 선택한다. CLI 설치·로그인은 사용자가 준비한다.

- `Tools → SnakeOrCamel → Run Agent…`: 프로필을 선택해 실행한다. 같은 프로젝트 세션에서 자체 생성한 프로필 탭을 재사용한다. IDE 재시작 후 이름만 같은 복원 탭을 자체 탭이라고 추정하지 않는다.
- `Insert File Reference into First Terminal Tab`: 편집기 우클릭 메뉴 또는 Tools 메뉴에서 실행한다. macOS는 ⌥⌘K, Windows/Linux는 Ctrl+Alt+K를 충돌이 없는 경우 연결한다. 충돌이 있으면 기존 배정을 유지하며 `Settings → Keymap`에서 사용자가 조정한다.
- 참조 액션은 활성 탭과 관계없이 Terminal 도구창의 화면상 첫 번째 탭을 사용한다. 분할된 도구창에서는 위쪽·왼쪽 탭 그룹을 먼저 사용한다.
- 빈 셸이면 기본 프로필을 실행한 뒤 같은 요청의 참조를 자동 삽입하고, 실행 중인 첫 탭에는 바로 삽입한다. 기존 질문을 유지하고 참조 양옆에 공백을 추가한다. 참조에는 Enter나 줄바꿈을 보내지 않는다.

선택이 없으면 `@src/Example.java`, 한 줄 선택이면 `@src/Example.java#L12`, 여러 줄이면 `@src/Example.java#L12-L34`를 삽입한다. 선택 끝이 다음 줄 시작이면 다음 줄은 제외한다. 겹치는 선택은 병합한다. 파일은 요청 시와 실제 삽입 직전에 저장한다. 디스크에 없는 편집기는 전달하지 않는다.

실제 세션 작업 디렉터리를 확인한 경우에만 그 내부 파일을 상대 경로로 표현한다. 그 밖에는 절대 경로를 사용한다. 특히 Classic 어댑터는 신뢰할 수 있는 공개 live 디렉터리 접근자가 없어 절대 경로를 사용한다. 공백이 있는 경로는 `@"한글 경로/예제.java"#L12` 형태를 생성한다. 이 인용 형식의 실제 CLI 파일·라인 해석은 아래 미검증 항목에 해당한다. 따옴표·제어 문자·백틱 등 표현할 수 없는 경로는 자동 삽입하지 않는다.

## 참조 삽입과 실행

연결된 첫 탭의 프로세스가 실행 중이면 답변 중·여러 줄 입력·승인 문구와 관계없이 참조를 즉시 삽입한다. 다른 프로그램이 실행 중이면 그 프로그램에 입력될 수 있다. 화면 텍스트나 Custom `readyPattern`은 삽입 허용 조건이 아니다. 프로세스 조회가 실패하거나 상태가 불명이어도 연결이 살아 있으면 삽입하며, 이 경우 자동 실행은 하지 않는다.

탭이 없으면 새 탭에서 기본 에이전트를 실행하고, 유휴 셸에서는 입력이 비어 있음이 확인된 경우 기본 에이전트를 실행한다. 최초 요청의 파일·선택 참조는 유지한다. 실행 후 최소 2초가 지나고 프로세스가 `RUNNING`임을 확인하면 Enter 없이 한 번 자동 삽입하므로 단축키를 다시 누를 필요가 없다. 기존 셸 명령이 있거나 빈 입력을 확인할 수 없으면 입력을 보존하고 안내한다.

새 셸 연결·프로세스 상태 확인은 요청 시점부터 최대 30초로 제한한다. 자체 실행 직후 `UNKNOWN`이면 확인될 때까지 기다리며, 셸로 돌아오면 실행 실패로 안내하고 참조를 폐기한다. 이는 이미 연결된 기존 프로그램에 명시적으로 삽입하는 `UNKNOWN` 정책과 구별된다. 2초 지연과 프로세스 확인은 CLI 입력창 준비를 보장하지 않으며 로그인·권한 승인 화면을 구분하지 않는다. 화면 문구 기반 준비 판정은 사용하지 않는다.

Classic 프로세스 조회는 백그라운드에서 수행한다. Modern은 공개 `TerminalView.hasChildProcesses` API를 사용하며 조회 불가 시 `UNKNOWN`으로 처리한다. 요청 중 OFF 전환·프로젝트 종료·대상 탭 이동 또는 닫힘·연결 교체가 발생하면 취소하고 새 첫 탭으로 재지정하지 않는다. 같은 세션과 참조의 처리 중 중복 요청은 합친다. 전송 오류는 자동 재시도하지 않는다. 성공하면 대상 탭에 포커스를 준다.

진단 로그에는 엔진·상태·처리 단계와 예외 종류·스택 위치만 기록한다. 터미널 본문·참조 경로·원본 예외 메시지는 기록하지 않는다. Terminal 플러그인은 선택 의존성이며 없어도 이름 변환과 JSON Prettier를 사용할 수 있다. Classic과 Reworked를 지원하며 2026.2.4 공개 API를 직접 사용한다. 다른 IDE·후속 버전의 동작은 별도 확인이 필요하다.

기존 Claude·Codex 플러그인의 명령·환경·IDE 연결·자동 컨텍스트 공유는 변경하지 않는다. SnakeOrCamel 참조 삽입과 각 플러그인의 자동 컨텍스트 공유는 별개다.

## Java 25 단일 기준 전환 확인

Java 25와 IntelliJ IDEA 2026.2.4에서 `compileJava compileTestJava buildPlugin`이 성공했다. 배포 ZIP의 플러그인 클래스 47개는 모두 major 69이며, 최소 IDE 빌드는 `262.11879.100`이다. 테스트 실행, Plugin Verifier, 실제 IDE UI 검증은 아직 수행하지 않았다. 사용자 검증 명령은 `./gradlew clean build verifyPlugin`과 `./gradlew runIde`이다.

## 2026-11-02 기존 구현 검증 기록

아래 결과는 직접 삽입 정책 및 Java 25 단일 기준 전환 이전 기록이다. 현재 버전의 검증 결과로 사용하지 않는다. 새 정책의 회귀 테스트 코드는 추가했으며 테스트 실행과 실제 IDE 검증은 사용자가 수행한다.

환경: macOS arm64, Gradle 실행·컴파일 JDK 25, Java 21 출력, 편집기 fixture 실행 JDK 21. 지원 검증 대상은 IC-242.20224.300(2024.2)과 IU-262.11879.100(2026.2.4)이다.

위 CLI 검사는 IDE 내부 터미널 검사가 아니다. 질문을 제출하지 않았으므로 실제 파일 읽기·라인 해석 성공을 의미하지 않는다. 현재 구현은 직접 참조 삽입에서 출력 화면을 판정하지 않는다. Reworked는 shell integration 없이 빈 셸 입력을 확정할 수 없으므로 유휴 셸에서의 자동 실행은 보류한다.

### 남은 실제 UI 검증

실행한 Gradle 샌드박스는 macOS에서 별도 Java 앱으로 나타났으나, 이번 환경의 UI 자동화 도구가 해당 앱을 선택하지 못했다(`Invalid app`, `Running application not found`). 사용자 IDE를 대신 조작하지 않았다. 아래 항목은 통과로 표시하지 않으며 배포 전 IntelliJ IDEA 2026.2.4의 Classic·Reworked에서 확인해야 한다.

- 설정 페이지 표시, OFF·ON·OFF·재시작, 실제 Keymap 연결·사용자 변경 보존, Terminal 비활성 상태의 기존 기능.
- 공존 플러그인 없음·Claude만·Codex만·둘 다 설치 및 설치됐지만 비활성화된 조합. 현재 지원 대상인 2026.2.4에서 확인한다.
- 두 번째 탭 활성 상태, 실제 화면상의 탭 이동·종료·분할, 외부 플러그인이 만든 첫 탭 재사용과 중복 실행 방지.
- 실제 IDE Terminal의 빈 탭·빈 셸 기본 에이전트 실행 후 원래 참조 자동 삽입, 시작 중 중복 요청 병합과 실행 실패 시 셸 입력 방지, 미전송 셸 입력 보존, 다른 프로그램·답변 중·승인 문구·UNKNOWN 상태 직접 삽입, Custom readyPattern 무관 동작.
- Claude·Codex의 실제 파일·라인 해석: 상대·절대 경로, 외부 파일, 한글·공백 경로, 기존 질문 유지와 Enter 미전송.
- 기존 이름 변환(멀티 커서·Undo/Redo), JSON 포맷·접기·펼치기·배열 수·복사·오류 표시.

확인한 결과에는 IDE·CLI·공존 플러그인 버전, OS·셸·엔진, 기대·실제 결과를 함께 기록한다. 자동 테스트와 바이너리 호환성 검사로 위 UI 검증을 대체하지 않는다.
